# A simple website

A simple single-page personal website, deployed with GitHub Pages.

## About

Static landing page with a short intro and links to LinkedIn and GitHub, plus a small blog section.

## Tech stack

- Plain HTML
- [Tailwind CSS](https://tailwindcss.com/) (via CDN, browser build)
- [Figtree](https://fonts.google.com/specimen/Figtree) Google Font

No build step, no dependencies to install — it's a single `index.html` file.

## Local preview

Just open `index.html` in your browser.

## Deployment

This site is deployed via [GitHub Pages](https://pages.github.com/).

1. Push changes to the `main` branch.
2. In the repo settings, under **Pages**, set the source to `main` / root.
3. The site will be published at `https://<username>.github.io/<repo>/`.

## Editing

All content lives in `index.html`. Update the text, links, and post entries directly there — no templating or CMS involved.
